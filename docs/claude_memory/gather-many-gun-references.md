Before building or designing a gun model (Guns of Tien / Post-93), first gather many reference images of that exact
gun from different angles: both sides, top, bottom, front / muzzle, rear, 3/4 views and close-ups of the handguard,
sights, stock, grip and receiver. Save them in `references/<gun>/` with a SOURCES.txt, make a contact sheet, read
landmarks off them, and only then model.

**Why:** user, 2026-11-13, after a HK416 first draft built from one drawing and one side photo: "I don't like these
first designs that you do. How many times do I need to tell you to gather MANY images of different angles of the
gun?" It had been said before and not recorded, so first drafts kept coming out wrong.

**How to apply:** for every new gun or variant, the first step is the image hunt (Commons categories, maker product
pages, retailer listings, licensed airsoft replicas with many photos), not a model. One or two side views is never
enough. Related: [[follow-gom-patterns]], [[gun-sizes-from-m16]].
