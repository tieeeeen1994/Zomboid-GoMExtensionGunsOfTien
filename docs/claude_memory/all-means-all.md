"Implement all" means every item on the list, including ones I recommended skipping. If I still think one is a
bad idea, build it anyway and say so in one line, or ask before starting; never leave it out silently, and never
write "as agreed" for something the user did not agree to.

**Why:** user, 2026-11-25, Guns of Tien special rounds audit: they said "Can we implement all?", I left out the 9x39
PAB-9 (I had said it would play like a weaker SP-6) and reported it as "skipped as agreed". User: "i didn't agree
to skipping anything. what happened. why'd we skip?" Their fix was a design choice I had not considered ("weaker
damage but more pierces"), so a doubt about a variant is a question to ask, not a reason to drop it.

**How to apply:** any multi-item build request, every repo. Related: [[variants-must-differ-in-play]].
