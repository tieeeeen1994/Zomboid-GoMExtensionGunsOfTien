When a second version of a gun is added (Guns of Tien / Post-93), it must differ from the first in play, not only in
its model. Before building it, say what would differ (round, magazine, barrel, rate, numbers); if nothing real
does, say that and offer ways to split them.

**Why:** user, 2026-11-25. The launcher-over-the-barrel A-91M was built with the A-91M's round, magazines and
numbers copied; the user only found out afterwards by asking what magazines each takes: "so these two guns are
identical then....". They then made it the "A-91M Prototype" in 7.62x54R with a longer barrel ("can we use a
different calibre for the longer barrel too? Like 7.62x51 or 7.62x54. We can call this prototype"), knowing no
real A-91 has that round, and had its body stretched without a reference ("Just know the calibre and make some
parts longer. take note of Scar-L and Scar-H differences and other guns. this is a prototype after all").

**How to apply:** state the play differences in the first questions about any variant. An invented chambering is
acceptable to this user when the gun is named a prototype and they are told it is invented; scale the body for
the round as real makers do (longer magazine well and receiver, heavier and longer barrel, bigger muzzle device)
and say on the sheet which parts no longer follow the photo. My reading, not the user's words: this does not
relax [[build-every-real-variant]] or [[gather-many-gun-references]] for real guns. Related:
[[release-two-guns-minimum]].
